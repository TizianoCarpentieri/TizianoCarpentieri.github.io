How it works

Tools change.Foundations hold.

ProjectLearns anchors an entry map and lean working rules inside your folder — so your project keeps growing regardless of harness, sessions, agent count, or LLM.

Without foundations, every project stalls early.

Order in place: your map and rules become foundations.

Switch harness, LLMs, or agent count — nobody starts over.

Four modes

One skill.Four moments.

Start.New folder? Sets up a light, proportionate base.
Adopt.Existing files? Links them in place and asks before moving.
Learn.Verified lesson? Turns it into a short rule and check.
Audit.Read-only review of links, drift, and stale rules.
In your folder

Plain Markdown.Nothing hidden.

AGENTS.md

Shared working rules learned from real work — when it applies, what to do, how to check it — plus a lean rule that replaces outdated entries in place.

PROJECT_INDEX.md

A brief entry map with relative links saying when to open each source or area, reusing an existing index when you already have one.

No lock-in

Plain Markdown files, no executable scripts, no cloud sync. Any agent that reads project instructions picks up without re-explaining context.

Still in testing

Initial adoption was tested on a standalone folder in Codex. End-to-end live runs of 1.0.0 across multi-domain folders and other agents are still open and tracked in the README.
